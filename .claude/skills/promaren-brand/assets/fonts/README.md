# Шрифты PROMAREN

Две гарнитуры, четыре голоса. Правила — раздел 8 брендбука; здесь только то,
какой файл брать и почему их два вида.

## Какой файл брать

**Ставите шрифт в браузер или собираете PDF — берите `woff2`.** Их восемь:
подмножества по алфавитам (`latin`, `latin-ext`, `cyrillic`, `cyrillic-ext`)
для каждой гарнитуры. Браузер скачает только те, что нужны странице, и это
единственная причина, по которой шрифт разрезан.

**Рисуете картинку кодом — берите `ttf`.** Pillow, ImageMagick, matplotlib,
любой генератор обложек и подписей читают `ttf` и `otf`; `woff2` не читает
ни один из них — это формат для CSS и больше ни для чего.

| Файл | Оси | Голос | Где применяется |
| -- | -- | -- | -- |
| `MartianMono-Display.ttf` | wght 500, wdth 87,5 | дисплейный | заголовки и показания: цена, срок, процент |
| `MartianMono-Mark.ttf` | wght 400, wdth 75 | служебный | обозначения разделов, единицы, метки |
| `Inter-Regular.ttf` | wght 400, opsz 14 | текстовый | вся проза |
| `Inter-SemiBold.ttf` | wght 600, opsz 14 | текстовый, акцент | подписи, выделения в тексте |

Файлов ровно четыре, потому что голосов четыре. Веса, которого нет в этой
таблице, нет и в комплекте — набрать им заголовок нечем, и это сделано
намеренно.

```python
from PIL import ImageFont
display = ImageFont.truetype("fonts/MartianMono-Display.ttf", 48)
mark    = ImageFont.truetype("fonts/MartianMono-Mark.ttf", 18)
body    = ImageFont.truetype("fonts/Inter-Regular.ttf", 28)
```

Капитель и разрядку служебного голоса шрифт не делает сам — их задаёт тот,
кто рисует: буквы в верхнем регистре, межбуквенное расстояние 0,16 em.

## Откуда они берутся

`scripts/build-brand-fonts.py` скачивает исходные переменные файлы у
производителя (репозиторий Google Fonts, откуда шрифты уходят и на
fonts.google.com) и закрепляет по ним нужные начертания. Руками файлы не
правятся и не перегоняются на месте.

```bash
docker run --rm -v "$PWD:/w" -w /w python:3-alpine sh -c \
  "pip install --quiet fonttools brotli && python scripts/build-brand-fonts.py"
```

Скрипт проверяет результат сам: в каждом файле должны быть цифры, кириллица,
латиница, `₽`, тире и кавычки-ёлочки, и ни один не должен остаться
переменным. Не сошлось — падает с именем файла и списком недостающих
символов.

## Почему это стоило отдельной работы

До 09.09.2026 здесь лежали только `woff2`. Проект `marina-channel-os`, который
рисует обложки постов кодом, перегонял их у себя — и **Martian Mono перегнать
не смог**: сшивались подмножества с сайта, а `fontTools.merge` не умеет
переменные шрифты, и в кириллическом подмножестве Martian Mono нет даже цифр.
Полгода заголовки обложек канала набирались Inter вместо Martian Mono —
прямое нарушение раздела 8, записанное в трёх местах как временное
отступление.

Разрешилось не техникой сшивания, а источником: у производителя обе гарнитуры
лежат **одним** переменным файлом, где латиница, кириллица и цифры уже вместе.
Сшивать нечего.
