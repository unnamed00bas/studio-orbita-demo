# Карточки для соцсетей

Мастер-шаблон карточек по брендбуку (раздел 15) и генератор PNG к нему.
Шаблон один на все носители: графит, обозначение служебным голосом сверху
слева, заголовок дисплейным, одно показание янтарём, знак белым снизу
слева на волосе. Меняется только текст.

Зачем это код, а не макет в Figma или Canva: карточка — одна фраза и одно
показание, всё остальное обязано совпадать на каждой. Макет в редакторе
расползается через месяц (сдвинули знак, подобрали «похожий» шрифт), а
шрифты здесь те же файлы, что в PDF и на сайте (`docs/brand/fonts/`).

## Файлы

- `card.html` — шаблон: размеры, виды содержимого, стили.
- `examples.json` — примеры на каждый формат и вид; из них собирается
  `examples/*.png`. Это и витрина, и регрессионный набор: после правки
  шаблона пересобрать и посмотреть глазами.
- `../../../scripts/build-social-card.mjs` — генератор.

## Форматы

| `format` | Размер, px | Носитель |
|---|---|---|
| `feed` | 1080 × 1350 | лента Telegram, VK, LinkedIn; слайды карусели |
| `story` | 1080 × 1920 | сторис, обложка Shorts; верх и низ свободны под интерфейс площадки |
| `og` | 1200 × 630 | превью для ссылок |
| `yt` | 1280 × 720 | обложка YouTube |
| `post` | 1600 × 900 | обложка поста канала (MAX, Telegram) — 16:9 |

## Виды содержимого

| `kind` | Что на карточке | Поля |
|---|---|---|
| `readout` | показание янтарём, подпись к нему, заголовок | `value`, `label`, `title`, при необходимости `body` |
| `statement` | заголовок и абзац | `title`, `body` |
| `quote` | заголовок и цитата с засечкой — рубрики «Отказ», «Условия» | `title`, `body` |
| `link` | последний слайд карусели: заголовок, абзац, один адрес | `title`, `body`, `url` |
| `cover` | превью для ссылок: знак по центру и одно предложение | `title` (только `format: og`) |

Общие поля: `mark` — обозначение сверху слева (рубрика), `aside` — подпись
снизу справа: адрес страницы, номер слайда «2 / 3», хронометраж ролика.
Цифры в `value` — только из библиотеки доказательств (брендбук, раздел 17).

## Сборка

Одна карточка:

```sh
node scripts/build-social-card.mjs --format feed --kind readout \
  --mark "Показание недели" --value "108 417" \
  --label "просмотров за 28 дней, старт с 12 подписчиков" \
  --title "Без съёмок и рекламного бюджета" \
  --aside promaren.ru/cases/eko-friend --out card.png
```

Серия (карусель, рубрика) из JSON-файла того же вида, что `examples.json`:

```sh
node scripts/build-social-card.mjs --json cards.json --out-dir ./out
```

Пересобрать примеры после правки шаблона:

```sh
node scripts/build-social-card.mjs --examples
```

Нужен Chromium (в образе агента он есть; иначе `CHROME_PATH=/путь/к/chrome`).
`KEEP_HTML=1` оставляет промежуточный HTML в `.social-card-tmp/` — удобно
править шаблон, открыв его в браузере.

## Что проверить перед публикацией

Чек-лист брендбука, раздел 18, плюс своё: показание одно, цифра из
библиотеки доказательств, эмодзи и второго цвета нет, у сторис текст не
заходит в верхние и нижние зоны, у карусели первый слайд — зацеп,
последний — выход с одной ссылкой.
